# Starting a New App From This Template

Everything to change, in the order it usually comes up. `com.praxis.apptemplate` /
`app-template` / `myapp.com` are the placeholder values used throughout this repo — search for
them.

## 1. Naming

- `app/app.json`: `expo.name`, `expo.slug`, `expo.scheme`, `expo.ios.bundleIdentifier`,
  `expo.android.package`.
- `app/app.config.js`, `docs/*.md`: anywhere `com.praxis.apptemplate` appears (bundle
  id/package name references).
- `app/package.json`, `server/package.json`, root `package.json`: `name` fields.
- Root `package.json` / repo name on GitHub.
- Replace the placeholder assets generated by `scripts/generate-placeholder-assets.js`
  (`app/assets/icon.png`, `adaptive-icon.png`, `splash.png`, `favicon.png`) with real artwork.
- `app/app/index.tsx`: the landing page copy.

## 2. Supabase (docs/SETUP_SUPABASE.md)

- New Supabase project (local + hosted).
- `supabase/config.toml`'s `project_id`, `site_url`, `additional_redirect_urls`.
- New `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` / `SUPABASE_JWT_SECRET` in `server/.env`.
- New `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY` in `app/.env`.

## 3. Google Sign-In (docs/SETUP_GOOGLE_OAUTH.md)

- New GCP project, new OAuth consent screen, three new OAuth client IDs (Web/iOS/Android) tied
  to your new bundle id/package name.
- New Firebase project + `app/google-services.json` (Android).
- New `EXPO_PUBLIC_GOOGLE_*` vars in `app/.env`, new `SUPABASE_AUTH_EXTERNAL_GOOGLE_*` in the
  repo-root `.env` and the hosted Supabase project's dashboard.

## 4. Apple Sign-In (docs/SETUP_APPLE_SIGNIN.md)

- Sign In with Apple capability on your new App ID.
- New Services ID + private key.
- New `SUPABASE_AUTH_EXTERNAL_APPLE_*` in the repo-root `.env` and the hosted Supabase
  project's dashboard.

## 5. EAS (docs/SETUP_EAS.md)

- `eas init` from `app/` — this writes a fresh `extra.eas.projectId`, don't copy the old one.
- New signing credentials (`eas credentials`) — these are tied to the bundle id/package name.

## 6. Domain and deploys (docs/DEPLOY_WEB_BACKEND.md, docs/DEPLOY_APP_STORES.md)

- Pick your real domain, replace every `myapp.com` reference (`supabase/config.toml`,
  `server/.env.example`'s `CORS_ORIGINS`, `app/.env.example`'s `EXPO_PUBLIC_API_URL`).
- New Play Console app / App Store Connect app record.
- New privacy policy URL, hosted wherever the web app ends up living.
